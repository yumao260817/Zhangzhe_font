## 艺术海报网页应用生成
- **任务**：使用 `data/target/` 下 14 张手写汉字 PNG（苟利国家生死以岂因祸福避趋之）生成艺术海报，用途为网页背景图。

- **设计风格**：宣纸水墨 + 传统竖排对联（右列苟利国家生死以 / 左列岂因祸福避趋之）+ 朱砂印章（则徐）+ 题款（林则徐《赴戍登程口占示家人》）。

  - 用 Python 脚本 `scripts/gen_poster_app.py` 自动化生成（读 PNG → base64 → 嵌入 HTML）。
  - 用 headless Chrome 截图验证视觉效果（1920×1080）。
  - 对字符 img 添加 `mix-blend-mode: multiply` 防白底溢出。
- **文件**：`scripts/gen_poster_app.py`（生成器）、`webapp/index.html`（交付物）、`webapp/preview2.png`（渲染截图）。
